## What is rName?

rName renames your files in bulk, calmly and without surprises. Drop in a folder, build your rules, and the table in the middle shows you every new name next to the old one right away: nothing is touched on disk until you say so. Everything happens right on your Mac, with no uploads and no account.

## Key Features

- **Eight rules to combine**: the new name comes from a chain of rules applied in order, which you drag to reorder and switch off without removing
- **Replace**: find and replace text, with regular expressions and `$1` groups too
- **Insert, remove, number**: a prefix, a suffix, or text at an exact position; a range of characters, the first or last ones, or a recurring pattern; running sequences with start, step, digits, and separator
- **Letter case, dates, and extensions**: lower case, UPPER CASE, Title Case, camelCase, PascalCase, snake_case, kebab-case; the creation date, the modification date, or today's, in the format you pick; an extension to set, normalise, or remove
- **Clean up the name**: double spaces, accents, emoji, invalid characters, spaces turned into `_` or `-`. Every rule can act on the name only, the extension only, or the whole file name
- **Presets**: save a chain and call it back with one click; four are ready to use — Tidy up names, Number in sequence, Date prefix, Web-friendly names
- **The preview is always there**: see the result next to the current name before you confirm
- **Conflicts set aside**: names that would collide, files already on disk, invalid characters, names that are too long. Those files stay out of the operation instead of breaking it
- **Undo (⌥⌘Z)**: puts the files from the last operation back to their previous names
- **One file at a time, too**: double-click a row and type the name by hand; that file stops following the rules until you send it back to the computed name
- **Swaps and capitalisation**: swapping two names, or changing just the capitalisation, works, because rName goes through a temporary name and puts the original back if anything fails
- **Permissions under control**: renaming requires access to the folder holding the file; rName asks once per folder, and Settings › Permissions lists them all so you can revoke any of them whenever you like
- **Built for macOS**: drag into the window or onto the Dock icon, "Open With…" in Finder, keyboard shortcuts (⌘O, ⇧⌘O, ⌘⏎, ⌥⌘Z)
- **Light, dark, or automatic appearance**: interface in English and Italian
- **No subscription**: free, with no ads and no in-app purchases
