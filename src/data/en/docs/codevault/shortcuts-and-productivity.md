## Keyboard Shortcuts (macOS & iPadOS)

Accelerate your coding workflow with native keyboard combinations:

| Shortcut | Action |
| :--- | :--- |
| <kbd>⌘</kbd> <kbd>N</kbd> | New code snippet |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | New Markdown note |
| <kbd>⌘</kbd> <kbd>F</kbd> | Focus instant search bar |
| <kbd>⌘</kbd> <kbd>C</kbd> (in list) | Copy snippet code to clipboard |
| <kbd>⌘</kbd> <kbd>D</kbd> | Duplicate selected item |
| <kbd>⌘</kbd> <kbd>⌫</kbd> | Move selected item to Trash |
| <kbd>⌘</kbd> <kbd>,</kbd> | Open App Settings |
| <kbd>⌘</kbd> <kbd>W</kbd> | Close current window |

## Clipboard & System Integration

- **Discreet Copy Feedback**: copying a snippet triggers subtle visual confirmation and haptics so you know the code is ready to paste.
- **Drag & Drop Import**: drag text files or source files directly into CodeVault to automatically generate snippets, detecting the language from the file extension.
- **Native Share Sheet**: share snippets and notes through Mail, Messages, or developer utilities without leaving the app.
