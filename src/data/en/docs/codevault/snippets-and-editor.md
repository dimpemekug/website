## Item Types

CodeVault supports two primary item types:

1. **Code Snippets**: blocks of source code tied to a specific programming language, featuring custom syntax highlighting, monospaced typography, and line numbers.
2. **Technical Notes**: plain text or Markdown notes ideal for documenting deployment steps, architectural diagrams, terminal commands, or study guides.

---

## Code Editor and Supported Languages

The native CodeVault editor is lightweight and responsive:
- **Line Numbers**: toggle line numbering on or off according to preference.
- **Monospaced Typography**: uses clean monospaced system or Fira Code font for optimal readability of indentations and symbols.
- **One-Click Quick Copy**: copy the entire snippet to your clipboard without manual text selection.

### Supported Languages
The `ProgrammingLanguage` enum supports over 20 modern environments:
- **Apple Ecosystem**: Swift, Objective-C
- **Web & Backend**: TypeScript, JavaScript, HTML, CSS, PHP, Python, Ruby, Go, Rust, Java, Kotlin
- **Systems & Scripting**: C, C++, C#, Bash/Shell, PowerShell, SQL, Dockerfile, YAML, JSON, Markdown, Plain Text

---

## Organization: Folders, Tags, and Favorites

- **Folders & Collections**: group snippets by project, technology stack, or client.
- **Multi-Value Tags**: assign flexible tags (e.g., `#devops`, `#security`, `#api`) for cross-cutting views.
- **Favorites**: mark essential snippets with a star to pin them in the favorites sidebar section.
- **Search & Filters**: quickly filter by language, tag, or folder directly from the search bar.
