The standard macOS shortcuts work as well: <kbd>⌘</kbd> <kbd>N</kbd>, <kbd>⌘</kbd> <kbd>O</kbd>, <kbd>⌘</kbd> <kbd>S</kbd>, <kbd>⌘</kbd> <kbd>Z</kbd>, <kbd>⌘</kbd> <kbd>F</kbd>, <kbd>⌘</kbd> <kbd>,</kbd> and so on.

On iPad with a keyboard, the same shortcuts work for styles, alignment, indents, lists, comments, tracked changes, Advanced Find and printing.

## File and edit

| Command | Shortcut |
|---|---|
| New from Template… | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> |
| Page Setup… | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>P</kbd> |
| Print… | <kbd>⌘</kbd> <kbd>P</kbd> |
| Find and Replace… | <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> |
| Look Up in Dictionary | <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>D</kbd> |
| Track Changes | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>E</kbd> |

## In the text and on objects

- <kbd>Tab</kbd> and <kbd>⇧</kbd> <kbd>Tab</kbd> at the start of a list item change its level.
- Double-click in the top or bottom margin: edit the header and footer; <kbd>Return</kbd> or <kbd>Esc</kbd> to close.
- <kbd>⇧</kbd>- or <kbd>⌘</kbd>-click: adds an object to the selection; the arrow keys move the selected objects.
