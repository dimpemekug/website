## Transfers

| Shortcut | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | Add Link or Torrent… |
| <kbd>⌘</kbd> <kbd>V</kbd> | with the list active, adds the link on the clipboard |
| <kbd>Space</kbd> | pauses or resumes the selected transfer |
| <kbd>⌘</kbd> <kbd>P</kbd> | Pause / Resume |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | Pause All |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>R</kbd> | Resume All |
| <kbd>⌘</kbd> <kbd>I</kbd> | Show or hide details |
| <kbd>⌫</kbd> | deletes the selected transfer, after confirmation |

The named items are also in the **Transfers** menu (and **File** for adding).

## Panels and search

| Shortcut | Action |
|---|---|
| <kbd>↩</kbd> | in the Add panel: **Add Download**; in Search files: starts the search |
| <kbd>esc</kbd> | closes the Add panel |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | shows or hides the sidebar |
| <kbd>⌘</kbd> <kbd>Q</kbd> | quits OmniPeer and stops the engine |
