On the Mac: **Charta › Settings…** (<kbd>⌘</kbd> <kbd>,</kbd>), with the **General**, **Editor** and **Preview** tabs. On iPhone and iPad: **Settings** in a document's toolbar menu or in a folder's **More** menu, on a single page. Settings apply to every document; those of a single project are covered in [Folders and linked notes](/en/projects/charta/docs/folders-and-linked-notes).

## General

| Setting | Values | Default |
|---|---|---|
| Open documents in | WYSIWYG, Code Editor | WYSIWYG |
| Open documents in tabs (Mac) | documents open as tabs of the active window | on |
| Appearance | System, Light, Dark | System |
| Language | System, Italiano, English | System |
| Reload Notes Changed by Other Apps (Mac) | in folders, a note with no unsaved changes reloads | on |

A new language takes effect at the next launch: on the Mac there's **Restart Now**, on iPhone and iPad just close and reopen Charta.

## WYSIWYG

| Setting | Values | Default |
|---|---|---|
| Font | System, Serif (New York), Rounded, Monospaced | System |
| Size | 10 to 32 pt on the Mac, 12 to 30 pt on iPhone and iPad | 16 pt |
| Line Spacing | 1 to 2 | 1.35 |
| Text Width (Mac) | Narrow, Medium, Wide, Full Window | Medium |
| Draw Formulas | drawn math or text | on |
| Draw Mermaid Diagrams | drawn diagrams or text | on |
| Always Show Front Matter | off: it only appears when the cursor reaches it | on |

## Code Editor

| Setting | Values | Default |
|---|---|---|
| Size | 10 to 28 pt on the Mac, 11 to 26 pt on iPhone and iPad | 14 pt |
| Line Numbers | | on |
| Highlight Current Line (Mac) | | on |

On the Mac, <kbd>⌘</kbd> <kbd>+</kbd> and <kbd>⌘</kbd> <kbd>-</kbd> change both sizes together.

## Writing

| Setting | Values | Default |
|---|---|---|
| Spell Checking | | on |
| Smart Quotes and Dashes | the system replaces straight quotes and dashes with typographic ones as you type | off |
| Image folder | folder next to the note for pasted or dropped images; empty: next to the note | `assets` |

## Preview

| Setting | Values | Default |
|---|---|---|
| Style | GitHub, Paper, Compact | GitHub |
| In the Code Editor (Mac) | Editor Only, Editor and Preview Side by Side, Preview Only | side by side |
| Synchronized Scrolling | | on |

The style is also used when exporting to HTML and PDF. On iPhone and iPad, choose the preview layout from the eye menu in the toolbar.

## What stays on your device

Settings, project settings, pinned and recent projects and recent notes stay in the app's preferences on your device; they don't sync between devices. The [privacy policy](/en/projects/charta/privacy/) explains what the app handles.
