Charta for iPhone and iPad has the same editor as the Mac: WYSIWYG, code editor, preview, folders, links, graph and exports. The commands change, designed for touch.

## Launch screen

At launch Charta shows your documents like the Files app, with two actions:

- **New Document**: a new Markdown file. Without iCloud it goes to the Charta folder in "On My iPhone" or "On My iPad".
- **Open Folder**: picks a folder to open as a project. On iPad it opens in its own window (you can keep several side by side), on iPhone full screen.

`.md` files also open when you tap them in the Files app. In a document window, the **Projects** button opens projects and recent notes.

## The toolbar

- the two-mode button, **WYSIWYG** and **Code Editor**;
- **Aa**: the **Format** menu, with styles, headings, lists, insert items and table commands;
- the eye, **View** menu: the preview layout (**Editor Only**, **Editor and Preview**, **Preview Only**), **Synchronized Scrolling**, **Outline**, the exports and **Print…**;
- in folders, **Backlinks**.

**Settings** is in a document's toolbar menu and in a folder's **More** (…) menu, next to **Note Graph**, **New Folder** and **Sort By**.

On iPhone the preview sits below the text, and the outline and backlinks open in a sheet; on iPad the preview sits beside the text and the sidebar stays alongside it.

## Bar above the keyboard

While you type, the bar above the keyboard shows, from the left:

- **Heading**: a menu from **Body Text** to **Heading 6**;
- **Bold**, **Italic**, **Bulleted List**, **Checklist**, **Link**;
- **Insert** (+): link to a note, image, table, code block, formula, Mermaid diagram, footnote and divider;
- **Edit Table**: format, add and delete rows and columns, move rows and columns;
- **Decrease Indent** and **Increase Indent**;
- **Hide Keyboard**.

While you type a `[[…` link, the bar shows the matching notes instead (or headings, after `#`): tap one to complete the link.

With text selected, the edit menu also has **Format** (bold, italic, strikethrough, code, link); on a link there's **Open Link**.

## With a hardware keyboard

- <kbd>⌘</kbd> <kbd>B</kbd>, <kbd>⌘</kbd> <kbd>I</kbd>, <kbd>⌘</kbd> <kbd>K</kbd>: bold, italic, link;
- <kbd>⌘</kbd> <kbd>E</kbd>: WYSIWYG or code editor;
- Tab and <kbd>⇧</kbd> Tab: next and previous cell in tables, indentation in lists;
- in folders, <kbd>⌘</kbd> <kbd>T</kbd> for **Go to Note** and <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> for backlinks.

Hold <kbd>⌘</kbd> on iPad to see the list.

## What's Mac only

| | Mac | iPhone and iPad |
|---|---|---|
| Format and Insert menus with shortcuts | Yes | "Aa" menu and the bar above the keyboard |
| Focus Mode and Typewriter Mode | Yes | No |
| Documents in tabs | Yes | No |
| Bigger and smaller text from the keyboard | Yes | Size in Settings |
| Highlight current line (option) | Yes | Always on |
| Reload notes changed by other apps (option) | Yes | Always on |
| Copy Link [[…]] and Show in Finder | Yes | No |
| Images pasted into a document opened on its own | Yes, after allowing the folder | Folders only |
| Export | Save panel | Share sheet |
