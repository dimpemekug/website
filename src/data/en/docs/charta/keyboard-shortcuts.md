The standard macOS shortcuts also work: <kbd>⌘</kbd> <kbd>N</kbd>, <kbd>⌘</kbd> <kbd>O</kbd>, <kbd>⌘</kbd> <kbd>S</kbd>, <kbd>⌘</kbd> <kbd>Z</kbd>, <kbd>⌘</kbd> <kbd>F</kbd>, <kbd>⌘</kbd> <kbd>,</kbd> and so on. On iPad with a keyboard, the ones listed at the end work.

## File

| Command | Shortcut |
|---|---|
| New Note in Folder | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>N</kbd> |
| Go to Note… | <kbd>⌘</kbd> <kbd>T</kbd> |
| Note Graph | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>G</kbd> |
| Open Folder… | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>O</kbd> |
| Print… | <kbd>⌘</kbd> <kbd>P</kbd> |

|---|---|
| Link | <kbd>⌘</kbd> <kbd>K</kbd> |
| Link to a Note | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> |
| Image | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>I</kbd> |
| Table | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>T</kbd> |
| Code Block | <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>C</kbd> |

## Window

| Command | Shortcut |
|---|---|
| Welcome to Charta | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>1</kbd> |

## In the text

| Key | Effect |
|---|---|
| Return | in a list or a quote, continues the mark; on an empty item, leaves the list; in a table, moves to the row below |
| Tab · <kbd>⇧</kbd> Tab | in tables, next and previous cell; in lists, indentation |

## iPad with a keyboard

| Command | Shortcut |
|---|---|
| Bold · Italic · Link | <kbd>⌘</kbd> <kbd>B</kbd> · <kbd>⌘</kbd> <kbd>I</kbd> · <kbd>⌘</kbd> <kbd>K</kbd> |
| WYSIWYG or Code | <kbd>⌘</kbd> <kbd>E</kbd> |
| Go to Note (in folders) | <kbd>⌘</kbd> <kbd>T</kbd> |
| Backlinks (in folders) | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>B</kbd> |
