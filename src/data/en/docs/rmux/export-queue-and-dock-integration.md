## Background Job Queue

With rMux you don't have to wait for an export to finish before moving on to the next video:
- **Export now** with **Export…** (<kbd>⌘</kbd> <kbd>↩</kbd>), or use **Add to Queue** to line the export up.
- **Multiple windows**: open several videos in separate windows and prepare different cuts in parallel.
- **The queue keeps going** even if you close the video's window, and it is saved between launches.
- In the **Job Queue** window (<kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>J</kbd>) you see each export's progress, can start the queue, remove single jobs or clear completed ones.

---

## Dock and Notifications

- **Progress on the Dock**: while exports run, a progress bar appears on rMux's Dock icon.
- **Notification when done**: when an export or the whole queue finishes, macOS shows a notification (with sound) saying whether it succeeded. From the sidebar you can then open the file with **Show in Finder**.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>⌘</kbd> <kbd>I</kbd> | Set In point |
| <kbd>⌘</kbd> <kbd>O</kbd> | Set Out point |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> | Clear marks |
| <kbd>⌥</kbd> <kbd>←</kbd> / <kbd>⌥</kbd> <kbd>→</kbd> | Go to previous or next keyframe |
| <kbd>⌘</kbd> <kbd>↩</kbd> | Export |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>J</kbd> | Open the job queue |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>I</kbd> | Show or hide the inspector |

All except <kbd>⌘</kbd> <kbd>↩</kbd> and <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>I</kbd> can be **reassigned** in Settings: click the shortcut field and press the new combination.
