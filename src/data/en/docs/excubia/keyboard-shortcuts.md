## Connection alert

| Shortcut | Action |
|---|---|
| <kbd>⌘</kbd> <kbd>A</kbd> | Allow |
| <kbd>⌘</kbd> <kbd>B</kbd> | Block |

## Sheets and confirmation dialogs

| Shortcut | Action |
|---|---|
| <kbd>↩</kbd> | confirm (the blue button): save a rule, create the learning rules, continue in the first-launch tour… |
| <kbd>esc</kbd> | cancel and close the sheet |

## Window and menus

- <kbd>⌘</kbd> <kbd>Q</kbd> closes only the window: Excubia stays in the menu bar. To quit, use **Quit** in the panel.
- The **Help** menu has **Excubia Guide**, which opens the Guide page, and **Show Welcome Tour**, which reopens the first-launch tour.
