Settings are on the **Settings** page in the sidebar.

## Profile

**Standard** (default) or **Expert**: see [Modes and profiles](/en/projects/excubia/docs/modes-and-profiles).

## Protection

| Setting | Values |
|---|---|
| **Mode** | Ask (default), Allow silently, Block silently, Block everything |
| Expert only: **Allow Apple software**, **Allow signed apps**, **Check incoming connections**, **Allow macOS components**, **Allow Mac App Store apps** | only the first is on at first |

## Alerts

| Setting | Values |
|---|---|
| **Close unanswered alerts** | Never (default), 30 seconds, 1, 2 or 5 minutes |
| **Then** (with a timeout) | Block (default) or Allow, for that connection only |
| **Keep connection log** | Until restart (default), 1, 7 or 30 days |
| **Block apps' encrypted DNS** | off |
| **Notify blocked connections** | off; the first time, macOS asks for notification permission |

## General

| Setting | Values |
|---|---|
| **Open at login** | Excubia starts at login in the menu bar |
| **Menu bar** | Icon (default), Speed, Graph |
| **Keep Awake in the menu** | off; turning it off stops a running session |
| **Appearance** | System, Light, Dark |
| **Language** | System, English, Italiano; applies after **Restart** |

## Network filter

The filter's **Status**, **Open System Settings**, **Reinstall** and **Uninstall…**: see [Installing the filter](/en/projects/excubia/docs/installing-the-filter).

## Data

- **Rules**: **Import…** and **Export…** as JSON.
- **Connection log**: **Clear**.
