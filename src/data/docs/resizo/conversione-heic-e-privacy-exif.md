## Conversione Automatica da HEIC a JPEG

Gli scatti effettuati con iPhone e iPad vengono salvati di default nel formato ad alta efficienza di Apple (**HEIC / HEIF**). Sebbene eccellente per risparmiare memoria su iOS, il formato HEIC risulta spesso incompatibile con piattaforme web, portali istituzionali, sistemi Windows o software di grafica datati.

Con Resizo puoi:
1. Trascinare decine o centinaia di file `.heic` direttamente nella finestra.
2. Selezionare come formato di destinazione **JPEG**.
3. Scegliere se mantenere la dimensione originale oppure ridimensionare contemporaneamente.
4. Salvare: i file HEIC verranno decodificati e convertiti all'istante in standard JPEG compatibili universalmente su qualsiasi dispositivo.

## Pulizia dei Metadati EXIF e GPS

Le fotografie moderne memorizzano all'interno del file un'ingente quantità di informazioni invisibili ma accessibili a chiunque:
- Coordinate geografiche esatte (latitudine, longitudine, altitudine dell'abitazione o del luogo di scatto).
- Marca, modello di telefono/fotocamera, ottica e matricola hardware.
- Data, ora al secondo e parametri tecnici di esposizione (ISO, tempo, diaframma).

### Opzione "Rimuovi Metadati EXIF"
In Resizo, l'opzione per ripulire i metadati è **abilitata di default**:
- Durante l'esportazione, l'immagine viene ridisegnata in un nuovo canvas privo di header EXIF, TIFF e GPS.
- Se invece desideri preservare i metadati per archivi fotografici professionali, ti basta disattivare la casella nelle opzioni di salvataggio.
