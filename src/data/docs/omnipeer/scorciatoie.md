## Trasferimenti

| Scorciatoia | Azione |
|---|---|
| <kbd>⌘</kbd> <kbd>N</kbd> | Aggiungi Link o Torrent… |
| <kbd>⌘</kbd> <kbd>V</kbd> | con l'elenco attivo, aggiunge il link negli appunti |
| <kbd>Spazio</kbd> | mette in pausa o riprende il trasferimento selezionato |
| <kbd>⌘</kbd> <kbd>P</kbd> | Metti in pausa / Riprendi |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | Metti tutti in pausa |
| <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>R</kbd> | Riprendi tutti |
| <kbd>⌘</kbd> <kbd>I</kbd> | Mostra o nascondi i dettagli |
| <kbd>⌫</kbd> | elimina il trasferimento selezionato, dopo la conferma |

Le voci con un nome sono anche nel menu **Trasferimenti** (e **File** per l'aggiunta).

## Pannelli e ricerca

| Scorciatoia | Azione |
|---|---|
| <kbd>↩</kbd> | nel pannello Aggiungi: **Aggiungi Download**; in Cerca file: avvia la ricerca |
| <kbd>esc</kbd> | chiude il pannello Aggiungi |
| <kbd>⌘</kbd> <kbd>,</kbd> | Impostazioni |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | mostra o nasconde la barra laterale |
| <kbd>⌘</kbd> <kbd>Q</kbd> | esce da OmniPeer e ferma il motore |
