## Connessioni a Fonti Esterne

Oltre ai file archiviati localmente, rManga offre un'infrastruttura modulare per collegarsi a sorgenti esterne:

### Repository di Estensioni (Formato Aidoku)
- Puoi aggiungere repository di terze parti specificando l'URL del manifest (es. `https://.../index.min.json`).
- L'app supporta anche l'aggiunta automatica tramite deep link dedicato: aprendo in Safari un link con schema `rmanga://add-repo?url=...`, rManga si avvierà configurando automaticamente la sorgente.

### Server Remoti Suwayomi e Paperback
- Configura l'indirizzo IP locale o remoto del tuo server self-hosted Suwayomi per accedere a tutta la tua collezione domestica via rete locale o VPN.

## Download e Lettura Offline

Per leggere comodamente in viaggio o in aereo senza connessione:
- **Download Singolo o in Blocco**: tocca l'icona di download accanto a un capitolo, oppure scegli "Scarica tutti i capitoli non letti".
- **Gestore Coda di Download**: una schermata dedicata mostra lo stato di avanzamento dei download attivi in background.
- **Filtro Solo Scaricati**: nella libreria puoi attivare il filtro rapido "Solo scaricati" per consultare esclusivamente i volumi già salvati nella memoria del dispositivo.
