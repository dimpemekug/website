## Scorciatoie da tastiera

Su **Mac** CodeVault aggiunge questi comandi alla barra dei menu. Su **iPad** con tastiera sono disponibili <kbd>⌘</kbd> <kbd>N</kbd> e <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd>.

| Scorciatoia | Azione |
| :--- | :--- |
| <kbd>⌘</kbd> <kbd>N</kbd> | Nuovo snippet |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | Nuova nota |
| <kbd>⌘</kbd> <kbd>F</kbd> | Apri la ricerca |
| <kbd>⌘</kbd> <kbd>1</kbd> … <kbd>⌘</kbd> <kbd>5</kbd> | Vai a Home, Snippet, Note, Categorie, Cerca |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | Mostra o nascondi la barra laterale |
| <kbd>⌘</kbd> <kbd>E</kbd> | Esporta JSON |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>E</kbd> | Esporta Markdown |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>I</kbd> | Importa JSON |
| <kbd>⌘</kbd> <kbd>,</kbd> | Apri le Impostazioni |

## Appunti, condivisione e azioni rapide

- **Copia rapida**: copia il codice di uno snippet (tutti i blocchi) o il testo di una nota con un tocco; un avviso a schermo e, su iPhone, un feedback aptico confermano la copia.
- **Incolla dagli appunti**: quando crei uno snippet, se negli appunti c'è del testo l'app propone di incollarlo nel campo del codice e ne riconosce il linguaggio.
- **Condivisione nativa**: condividi snippet e note in Markdown con il foglio di condivisione di sistema verso Mail, Messaggi, Note o altre app.
- **Menu contestuale**: con un clic destro (Mac) o una pressione prolungata (iPhone e iPad) puoi fissare, duplicare, copiare, condividere o eliminare un elemento.
