## Scorciatoie da Tastiera (macOS e iPadOS)

Per consentire un flusso di lavoro fulmineo durante lo sviluppo, CodeVault supporta le seguenti combinazioni di tasti:

| Scorciatoia | Azione |
| :--- | :--- |
| <kbd>⌘</kbd> <kbd>N</kbd> | Crea un nuovo frammento di codice |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | Crea una nuova nota Markdown |
| <kbd>⌘</kbd> <kbd>F</kbd> | Attiva la barra di ricerca rapida |
| <kbd>⌘</kbd> <kbd>C</kbd> (in lista) | Copia negli appunti il codice dell'elemento selezionato |
| <kbd>⌘</kbd> <kbd>D</kbd> | Duplica l'elemento selezionato |
| <kbd>⌘</kbd> <kbd>⌫</kbd> | Sposta l'elemento selezionato nel Cestino |
| <kbd>⌘</kbd> <kbd>,</kbd> | Apri le Impostazioni dell'applicazione |
| <kbd>⌘</kbd> <kbd>W</kbd> | Chiudi la finestra corrente |

---

## Integrazione con gli Appunti e il Sistema

- **Copia con Notifica Discreta**: quando copi un frammento, un banner visivo o un feedback aptico conferma che il codice è pronto negli appunti.
- **Supporto Drag & Drop**: puoi trascinare file di testo o file sorgente direttamente nella lista di CodeVault per importarli all'istante come nuovi snippet con il linguaggio dedotto dall'estensione del file.
- **Condivisione Nativa**: condividi snippet e note tramite il foglio di condivisione di sistema verso Mail, Messaggi, Note o altre applicazioni di sviluppo.
